Free Proxy List Sources

Public, regularly updated proxy lists maintained by open-source projects. Each source publishes its own schedule and format; follow the links to view the latest data and usage terms.

  • monosans/proxy-list — HTTP, SOCKS4 and SOCKS5, re-checked hourly (MIT).
  • clarketm/proxy-list — HTTP forward proxies, updated daily (MIT).
  • TheSpeedX/PROXY-List — HTTP, SOCKS4 and SOCKS5, updated daily.
  • proxifly/free-proxy-list — HTTP, SOCKS4 and SOCKS5 with geolocation, updated every 5 minutes (GPL-3.0). JSON feed.

How to Use These Proxies with Telegram

The lists above include HTTP, SOCKS4 and SOCKS5 servers. Telegram supports SOCKS5 proxies, so you can use a working SOCKS5 entry from a source you trust.

  1. Load the proxifly list above, or open one of the source repositories, and pick a SOCKS5 proxy that is geographically close to you.
  2. Read the host and port from the proxy string. For example, socks5://203.0.113.10:1080 means host 203.0.113.10 and port 1080.
  3. In Telegram, open Settings → Advanced → Connection type → Add proxy (desktop: Settings → Advanced → Connection type).
  4. Choose SOCKS5, enter the host and port, then save. Most public proxies do not require a username or password.
  5. Enable the proxy and open a chat. If it does not connect, disable it and try another SOCKS5 entry; public proxies are often slow or offline.

On a school or college network, a proxy only works if the network allows outbound traffic to the proxy's port. If that traffic is blocked, use a trusted VPN or ask your network administrator instead.
